Residência em Análise e Visualização de Dados

Ago/2025 – Nov/2025

Residência intensiva de quatro meses dedicada à análise e visualização de dados, com foco em transformar informações em insights acionáveis.
Foram desenvolvidos dashboards interativos no Looker Studio, explorando desde a coleta e tratamento de dados até a criação de narrativas visuais claras e impactantes.
A experiência contou com projetos práticos orientados por mentores da PUC-Rio, reforçando o aprendizado em situações reais. Além do aspecto técnico, o programa também estimulou o desenvolvimento de habilidades colaborativas e de trabalho em equipe em ambiente remoto.

As pastas desse repositório estão organizadas de acordo com as etapas do programa de residencia. Em cada uma delas se encontra as fontes de dados utilizadas, o dashboard em pdf, os prints de partes do dashboard e um Readme explicando as análises e inisights.
